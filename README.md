# Among The Letters

Static promotional website for **Among The Letters**, a literary newsletter published on Substack.

## Purpose

This site is intentionally evergreen. It explains the publication and sends readers to Substack. It does not contain a CMS, newsletter database, payment system, article feed, current issue tracker, or other content that needs routine website updates.

Current publication rhythm:
- **Morning Opportunities:** Mondays and Thursdays
- **Afternoon Discoveries:** daily
- **Subscriptions and billing:** handled entirely by Substack

Substack: https://amongtheletters.substack.com/
